# Tiny Convoy

**README** – Overview of the web‑based low‑poly game creation platform.

## Project Summary
- **Name**: Tiny Convoy (tinyLOGY)
- **Goal**: Enable developers to build stylized low‑poly auto‑battler/logistics games directly in the browser.
- **Stack**: React + TypeScript, Vite, Three.js (Orthographic PS1 shaders), Rapier‑JS physics, Tiny‑ECS, Node/Express backend.

## Quick Start
```bash
# Clone
git clone https://github.com/naikdishant/tinyLOGY.git
cd tinyLOGY
# Install dependencies
npm install
# Run editor (dev server)
npm run dev
```
