# MVP Scope

## MVP Goal

Ship a browser-based editor that can create one small playable low-poly game loop end to end.

## Delivery Strategy

Build major systems first and leave polish, visual tuning, and minor UX details for the end.

## Included

- Project creation
- Scene editing
- Entity placement
- Template assignment
- Basic playtest loop
- Simple save/load
- Basic export path

## Excluded For MVP

- Multiplayer
- Large asset marketplace
- Advanced scripting IDE
- Complex physics
- Procedural world generation at scale
- Cross-platform native exports

## MVP Success Test

If a user can build a tiny game, play it in the browser, and export it without manual repair, the MVP succeeds.

## Scope Guard

If a feature does not help create, test, save, validate, or export the first playable loop, it is not MVP work.
