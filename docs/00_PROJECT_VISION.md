# Project Vision

## What This Is

A browser-based game creation platform for stylized low-poly games.

## What This Is Not

- Not a general-purpose AAA engine
- Not Unity
- Not a code-only tool
- Not multiplayer-first
- Not a shader editor product

## Product Goal

Let a user build, test, and export a small stylized game with minimal friction.

## Planning Rule

The project must be designed so any coding agent can work on one small subsystem at a time without needing the whole repo in context.

## Development Rule

The project should be built in phases, with each phase ending in a runnable or verifiable outcome before the next one begins.

## Primary User Outcomes

1. Create or open a project.
2. Build a scene from templates and assets.
3. Playtest immediately in the browser.
4. Export or share the result.

## Success Criteria

- A new project can be created from scratch.
- A scene can be edited and played without manual wiring.
- Templates and assets remain data-driven.
- The project can be maintained by an AI agent using these docs as the source of truth.
