# Product Overview

**Problem**: Creating low‑poly, auto‑battler or logistics‑style games requires a lot of boilerplate (asset pipelines, physics, UI) and steep learning curves.

**Target Users**:
- Indie developers seeking rapid prototyping.
- Hobbyists who want a visual, no‑code workflow.
- Educators teaching game design concepts.

**Value Proposition**:
- Browser‑based editor – no install.
- Opinionated low‑poly style constraints keep projects lightweight.
- Template‑driven approach eliminates boilerplate code.
- Immediate play‑test & one‑click export to web/desktop.

**User Journey**:
1. Create a new project → select a game template (Roguelite, Platformer…).
2. Choose a visual style (Low‑poly, PS1, Voxel). 
3. Drag‑and‑drop prefabs, configure rules via “WHEN‑IF‑DO”.
4. Test instantly in the browser.
5. Export the build.
